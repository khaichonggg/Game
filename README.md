# 碰碰球大乱斗 3D 🎱

轻量的多人在线 3D 派对小游戏：每个人控制一个戴着专属头饰的碰碰球，在岩浆海上的浮岛里互相冲撞。浮岛由一圈圈地砖组成，外圈会依次闪红、坍塌，把别人撞进岩浆，**最后留在场上的人得 1 分，先拿到 3 / 5 / 7 分（房主可选）获胜**。

- 浏览器打开就能玩，电脑和手机都支持
- 房间码 / 邀请链接，最多 8 人同房
- 人不够可以加机器人
- Three.js 3D 画面：程序化岩浆、可坍塌的地砖浮岛、带表情和头饰的角色、粒子特效
- 无需任何图片 / 模型素材，全部由代码生成；音效由 WebAudio 实时合成

## 道具

场地上会不定时刷出道具，碰到就能用：

| 道具 | 效果 |
| --- | --- |
| 🍄 巨大化 | 7 秒内体型变大、体重 ×3，横冲直撞 |
| ⚡ 加速 | 6 秒内加速度 ×1.7，冲刺冷却减半 |
| 🛡️ 护盾 | 6 秒内几乎推不动，撞过来的人会被弹飞 |
| 💣 炸弹 | 立即引爆冲击波，把周围所有人震飞 |

## 操作

| 平台 | 移动 | 冲刺 |
| --- | --- | --- |
| 电脑 | WASD / 方向键 | 空格（或 Shift / J） |
| 手机 | 左半屏拖动摇杆 | 右下角「冲刺」按钮 |

冲刺有 1.2 秒冷却，自己的球外圈黄色圆环满了就能再冲。

## 运行

需要 Node.js 18+。

```bash
npm install
npm start
```

打开 http://localhost:3000 ，点「创建房间」，再把「复制邀请链接」发给朋友即可。

- **同一个 Wi-Fi 下一起玩**：让朋友访问 `http://你的电脑局域网IP:3000`
- **远程一起玩**：部署到任意支持 Node + WebSocket 的平台（Render、Railway、Fly.io、自己的服务器等），启动命令 `npm start`，端口读取环境变量 `PORT`

## 结构

```
server.js         HTTP 静态服务 + WebSocket 房间与物理模拟（服务端权威）
public/index.html 页面结构
public/style.css  样式
public/game.js    客户端：Three.js 渲染、建模、特效、输入、音效、界面
public/vendor/    Three.js（已打包成单文件，无需额外安装）
```

可在 `server.js` 顶部调整玩法参数（每圈半径、坍塌时间、冲刺力度、弹性、道具时长等）。
