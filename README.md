# 碰碰球大乱斗 3D 🎱

轻量的多人在线 3D 派对小游戏：每个人控制一个戴着专属头饰的碰碰球，在各种会塌掉的场地上互相冲撞，把别人撞下去！

- 浏览器打开就能玩，电脑和手机都支持
- 房间码 / 邀请链接，最多 8 人同房，人不够可以加机器人
- 4 张地图 × 4 种模式 × 8 种道具
- 排行榜：自动记录每位真人玩家的夺冠次数、击飞数和场次
- Three.js 3D 画面，所有模型、贴图、音效都由代码生成，不需要任何素材文件

## 模式

| 模式 | 规则 | 可选目标 |
| --- | --- | --- |
| 🥊 经典乱斗 | 每局活到最后的人得 1 分 | 先赢 3 / 5 / 7 局 |
| ⚔️ 团队对抗 | 随机分成红蓝两队，全灭对面得 1 分 | 先赢 3 / 5 / 7 局 |
| 👑 抢皇冠 | 戴着皇冠就持续计时，用力撞持有者就能抢过来；掉下去会复活 | 先拿满 20 / 30 / 45 秒 |
| 💥 击飞大赛 | 限时无限复活，把人撞下去得 1 分 | 比赛 60 / 90 / 120 秒 |

## 运行

需要 Node.js 18+。

```bash
npm install
npm start
```

打开 http://localhost:3000 ，点「创建房间」，在大厅里选地图和模式，再把「复制邀请链接」发给朋友即可。

- **同一个 Wi-Fi 下一起玩**：让朋友访问 `http://你的电脑局域网IP:3000`
- **远程一起玩**：部署到任意支持 Node + WebSocket 的平台（Render、Railway、Fly.io、自己的服务器等），启动命令 `npm start`，端口读取环境变量 `PORT`

排行榜数据保存在 `data/leaderboard.json`，删除这个文件即可清空。

## 结构

```
server.js         HTTP 静态服务 + WebSocket 房间、模式规则、道具、机关、机器人（服务端权威物理）
maps.js           4 张地图的地砖布局与机关参数（服务端判定和客户端建模共用）
leaderboard.js    排行榜存储
public/index.html 页面结构
public/style.css  样式
public/game.js    客户端：Three.js 渲染、地图主题、角色和道具建模、特效、输入、音效、界面
public/vendor/    Three.js（已打包成单文件，无需额外安装）
```
